TEXT OBJECTS: i = inside, a = around. Read them out loud.

  ciw   change inside word         daw   delete a word (and its space)
  ci"   change inside "quotes"     da(   delete around (parens)
  di{   delete inside {braces}     yap   yank a paragraph
  cit   change inside <tag>        vi[   select inside [brackets]

The cursor only needs to be somewhere inside. That's the magic.

Try it:
  1. Change the string to "neovim" with ci" (cursor anywhere on the line):
       const editor = "notepad";

  2. Empty the function call with di(:
       launch(rocket, fuel, 3, 2, 1);

  3. Delete the whole argument list, parens included, with da(:
       launch(rocket, fuel, 3, 2, 1);

  4. Change the tag's text with cit:
       <h1>Hello world</h1>

  5. Delete this whole paragraph with dap.
     It has two lines,
     and then it's gone.
